대사와 성과 리포트

수집(원본 이벤트), 장부(과금 컨슈머), 예산(쓴 돈)은 서로 다른 곳에서 만들어집니다. 대사는 이 셋이 맞는지 보고, 성과는 광고주가 보는 숫자를 보여줍니다. 광고를 누르고 몇 초 뒤

대사
광고판정수집 클릭장부재전송처리 대기 과금10초 규칙예산 부족장부 합계쓴 돈미청구

판정: OK = 모두 맞음 / LAGGING = 수집 클릭 ≠ 장부 + 재전송(한쪽 컨슈머가 아직 처리 중) / MISMATCH = 장부 합계 ≠ 쓴 돈(반쪽 상태, 있으면 안 됨). 수집 단계에서 걸러진 봇 클릭(GIVT): 건

광고별 성과
광고렌더링viewable클릭CTR(렌더링)CTR(viewable) 과금 클릭광고비전환매출ROAS추정 광고비추정 ROAS

CTR은 같은 클릭 수를 어떤 노출로 나누느냐에 따라 달라집니다. ROAS는 장부의 실제 광고비 기준, 추정 ROAS는 3단계의 과금 규칙 적용 전 광고비 기준이며, 두 광고비의 차이가 과금하지 않은 클릭(부정 클릭, 예산 소진)입니다.
